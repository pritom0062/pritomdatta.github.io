# Pritom Datta — Professional Profile

A free, responsive professional profile website designed for job applications,
international recruiters, and academic/PhD outreach.

## Files

- `index.html` — website content and structure
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation
- `assets/profile.jpg` — placeholder image; replace with a professional photo
- `assets/cv/Pritom_Datta_CV.pdf` — CV download
- `README.md` — this guide

## Publish with GitHub Pages

1. Create a public GitHub repository named `<your-username>.github.io`.
2. Upload all files while preserving the folder structure.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.
7. Visit `https://<your-username>.github.io`.

## Before publishing

1. Replace `assets/profile.jpg` with your real professional photo.
2. Replace the placeholder GitHub URL in `index.html` with your actual GitHub profile.
3. Review every statement and make sure it accurately reflects your current experience.
4. Consider adding a Research Interests section after deciding which research areas you want to present to PhD supervisors.
